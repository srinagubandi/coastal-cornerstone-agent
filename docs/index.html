Ask a company question

Send UTF-8 JSON with exactly one field. Questions must contain 2–1,500 characters; request bodies are limited to 8 KB.

POST /ask
Content-Type: application/json

{"question":"Your company-information question"}

HTTP 200 returns either answered with exact curated answer text, FAQ IDs, and dataset source URLs, or needs_review with a non-invented fallback. review_queued indicates whether a sanitized question was retained privately; it does not mean an email was sent or an answer promised. HTTP 429 includes Retry-After.

Protective limits

Questions: 5/minute and 50/UTC day per client hash; 60/minute and 1,000/UTC day globally. Public reads: 120/minute per client and 1,200/minute globally. HTTP requests are additionally bounded by transport, body and connection limits.

Exact question/tag matches and validated cached selections avoid paid calls. Non-exact selection uses only the pinned DeepSeek model, with live price checks and transactional reservations under a $1 UTC-month model cap. At most three paid requests may be in flight.

Pricing, budget, provider or knowledge unavailability produces a fallback—not an invented answer.

MCP: a read-only tools subset

JSON-RPC 2.0 over POST /mcp supports initialize (negotiated version 2025-03-26), notifications/initialized, tools/list, and tools/call. The tools are get_faq (optional approved FAQ ID) and ask_company_question (question only). Requests share API protections. IDs are echoed; notifications receive HTTP 204.

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"client","version":"1"}}}
{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"ask_company_question","arguments":{"question":"Your company-information question"}}}

This is not full A2A compliance, a complete streamable MCP server, an SSE service, or an action-taking remote agent. No batch JSON-RPC, remote tools, arbitrary URLs, private CRM access, booking, quoting, emailing on request, engineering advice, warranty commitments, or availability claims are supported.

Grounding and privacy

The model can return only eligible FAQ IDs and a review flag. Unknown IDs and invalid output are rejected. The server, not the model, returns exact curated answers and only approved dataset sources. Questions never become knowledge automatically.

Real incoming API/MCP questions—including fallbacks and blocked attempts—are logged privately after basic email, phone, URL, IP and credential redaction. Salted IP hashes support rate limits without storing raw IPs. This provides limited pseudonymity, not guaranteed anonymity: names, addresses and contextual personal information may remain. Avoid submitting personal or confidential data. The service cannot authenticate an AI caller's identity without a caller credential; API/MCP labels describe transport, not verified identity.

Private events are retained for 30 days with a 10,000-event cap. Deduplicated review questions have a 30-day lifetime, a 100-new-question/UTC-day cap, and a 1,000-pending cap. Email digest delivery is paused by default and requires separate owner-approved configuration. No empty digest is sent.
